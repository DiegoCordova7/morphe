Typed · Pattern-matched · Own VM

A language built around shape, not just syntax.

Morphe is a strongly-typed language with structural pattern matching. Source compiles to bytecode and runs on a custom virtual machine you can inspect end to end.

Shape in, behavior out.

Declare a type, build a value, and let match take it apart by its shape. No visitors, no casts, no ceremony.

main.mrf 
type City {
  name : String;
}

func main() : Void {
  city : City = new City {
    name = "Moctezuma";
  };

  match (city) {
    City { name : "Moctezuma" } => {
      print(city.name);
    }
  }
}

From source to runtime.

Every stage is a small, readable piece you can inspect. The VM runs bytecode designed for Morphe, not borrowed from a host language.

  1. Source Your .mrf file, as plain text.
  2. Lexer Turns characters into tokens.
  3. Parser Builds the syntax tree.
  4. Semantic Checks types and structural shapes.
  5. Compiler Lowers the tree to instructions.
  6. Bytecode Compact instructions for the Morphe VM.
  7. VM Runtime Executes the program, step by step.

Why Morphe

Structured types

Data is declared as typed structures, so shapes are explicit and checked before a program ever runs.

Structural matching

match destructures values against a shape and a set of field constraints in one expression.

Own virtual machine

Compiled programs run on bytecode designed for Morphe, not borrowed from another host language.
